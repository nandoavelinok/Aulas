🛤️ Introdução ao Portugol

🎯 Aula: O que é Portugol, instalação, primeiros passos e conceitos fundamentais.

🤔 O que é o Portugol?

O Portugol é uma ferramenta educacional de programação baseada em pseudocódigo em português. Diferente das linguagens tradicionais (Python, Java, C++), utiliza comandos no nosso idioma, permitindo focar no raciocínio lógico sem se preocupar inicialmente com a sintaxe rígida do inglês.

🎯 Analogia prática:

Pense em Portugol como andar de bicicleta com rodinhas 🚴. Você aprende a equilibrar, pedalar e virar sem se preocupar com o trânsito. Quando tirar as rodinhas (migrar para Python/C++), você já sabe andar!

🎯 Por que começar com Portugol?

  • ✅ Comandos em português: escreva, leia, se, entao, para
  • ✅ Sintaxe simplificada: menos erros de digitação, mais foco na lógica
  • ✅ Ambiente visual: o interpretador mostra a execução passo a passo e o valor das variáveis em tempo real
  • ✅ Base sólida: tudo que aprender aqui serve para qualquer linguagem depois

🧠 O que é Lógica de Programação?

É a técnica de encadear pensamentos e instruções em uma sequência coerente para atingir um objetivo. Dominar essa lógica significa saber organizar ideias para que a máquina as compreenda e processe corretamente.

📦 Conceitos Fundamentais

  • 🏷️ Variáveis: "caixinhas" na memória que armazenam dados (números, textos, lógicos). Ex: idade, nome.
  • 🧮 Operadores aritméticos: + (soma), - (subtração), * (multiplicação), / (divisão), % (resto da divisão).
  • ⚖️ Operadores relacionais: == (igual), != (diferente), > (maior), < (menor), >= (maior ou igual), <= (menor ou igual).

  6. Servir e beber 😋

🧠 Lógica Proposicional

🎯 Aula: Conectivos lógicos, tabelas-verdade, precedência e aplicação prática no código.

📚 O que é uma Proposição?

Uma proposição é qualquer afirmação que pode ser classificada de forma inequívoca como verdadeira (V) ou falsa (F). Na lógica clássica, são representadas por letras minúsculas como p, q e r.

✅ Exemplos de proposições:
  • "Angola está em África" → V 🌍
  • "2 + 2 = 5" → F ❌
  • "O número 10 é par" → V 🔢
❌ NÃO são proposições (no contexto da lógica clássica):
  • "Que horas são?" (Pergunta / Interrogação)
  • "Feche a porta!" (Ordem / Imperativo)
  • "x + 2 = 5" (Sentença aberta: depende do valor de x)
  • "Que dia lindo!" (Exclamação / Opinião subjetiva)
💻 A Ponte para a Programação: Na programação, uma condição como idade >= 18 é uma proposição! O computador avalia essa expressão e ela se torna Verdadeira ou Falsa naquele momento exato, permitindo que o programa tome decisões.

🔗 Conectivos Lógicos

Usamos conectivos para unir proposições simples e formar proposições compostas. Veja como eles funcionam e como são escritos no Portugol:

ConectivoSímbolo MatemáticoSintaxe no PortugolRegra de OuroExemplo Prático
Conjunção ∧ e V se ambos forem V "É sábado e chove" 🌧️
Disjunção ∨ ou V se pelo menos um for V "Vou de 🚌 ou de 🚇"
Negação ¬ ou ~ nao Inverte o valor (V ↔ F) "Não estou com fome" 🙅

*Nota: Implicação (→) e Bi-implicação (↔) são mais usadas em matemática pura. No dia a dia da programação, focamos 99% do tempo em E, OU e NÃO.

💡 Macetes de Memorização:
  • E (∧): Pense em "Exigente" — só fica feliz se os dois estiverem verdadeiros.
  • OU (∨): Pense em "Generoso" — basta um estar verdadeiro para ele aceitar.
  • NÃO (¬): Pense no "Espelho" — inverte tudo o que vê.

⚠️ Precedência de Operadores (Muito Importante!)

Assim como na matemática a multiplicação vem antes da soma, na lógica existe uma ordem de resolução. Se não usarmos parênteses, o computador segue esta ordem:

OrdemOperadorExemplo
1º (Maior prioridade)Parênteses ()O que está dentro é resolvido primeiro
2ºNegação naonao V vira F
3ºConjunção eResolvido antes do "ou"
4º (Menor prioridade)Disjunção ouResolvido por último

🔍 Exemplo de Avaliação Passo a Passo

Vamos avaliar a expressão: nao (5 > 3) ou (2 == 2 e 1 != 1)

  1. 1. Resolver parênteses e relações: nao (V) ou (V e F)
  2. 2. Resolver o "e" dentro do 2º parênteses: nao (V) ou (F)
  3. 3. Resolver a negação "nao": F ou F
  4. 4. Resolver o "ou" final: F (Falso)

💻 Da Lógica para o Código (Portugol)

Veja como uma regra de negócio do mundo real se transforma em lógica de programação:

// Regra: Para entrar na festa, precisa ter 18 anos ou mais E ter convite.
inteiro idade = 20
logico tem_convite = verdadeiro

// A condição abaixo será avaliada como VERDADEIRA
se (idade >= 18 e tem_convite == verdadeiro) {
    escreva("Pode entrar na festa! 🎉")
}

💻 Declaração de Algoritmo

🎯 Aula: Estrutura básica, regras de nomenclatura, tipos de dados, operadores e comandos de entrada/saída.

📋 A Anatomia de um Programa

Todo algoritmo em Portugol segue uma estrutura rígida, como uma receita de bolo. Se faltar um ingrediente ou mudar a ordem, o programa não funciona.

programa {
        funcao inicio() {
        // 1. DECLARAÇÃO: Avisamos o computador quais caixas vamos usar
        inteiro idade
        real nota
        cadeia nome
        
        // 2. PROCESSAMENTO E E/S: Comandos que fazem o programa funcionar
        escreva("Digite seu nome: ")
        leia(nome)
        escreva("Olá, ", nome, "!")
        }
        }

⌨️ Comandos de Entrada e Saída (E/S)

  • 🖨️ escreva(): Imprime na tela e mantém o cursor na mesma linha.
  • ↩️ escreval(): Imprime na tela e pula uma linha no final (o "l" é de "linha").
  • ⌨️ leia(variavel): Pausa a execução do programa e espera o usuário digitar algo e pressionar Enter. O valor digitado é guardado na variável.
⚠️ O Erro Nº 1 dos Iniciantes: = vs ==
• = (um sinal) é ATRIBUIÇÃO: "Guarde este valor na variável". Ex: idade = 18
• == (dois sinais) é COMPARAÇÃO: "O valor da esquerda é igual ao da direita?". Ex: se (idade == 18)

🔀 Condição e Escolha

🎯 Aula: Estruturas condicionais: se/senao, aninhamento e escolha/caso para tomada de decisões.

Até agora, nossos programas eram sequenciais (faziam sempre a mesma coisa). Com as estruturas condicionais, o programa ganha a capacidade de tomar decisões e executar caminhos diferentes dependendo dos dados.

🔀 Estrutura SE / SENÃO

A estrutura básica permite executar um bloco de código se uma condição for verdadeira, e outro bloco (opcional) se for falsa.

se (condicao_verdadeira) {
    // instruções executadas APENAS se a condição for V ✅
} senao {
    // instruções executadas APENAS se a condição for F ❌
}

🔗 Encadeando Condições: O "Senão Se"

Quando há mais de duas possibilidades, usamos senao se para verificar novas condições em cascata. O computador para de verificar assim que encontra a primeira condição verdadeira.

programa {
    funcao inicio() {
        real media
        
        escreva("Digite a média do aluno: ")
        leia(media)
        
        se (media >= 14) {
            escreva("APROVADO com Distinção ✅")
        } senao se (media >= 10) {
            escreva("APROVADO ✅")
        } senao se (media >= 7) {
            escreva("RECUPERAÇÃO 🟡")
        } senao {
            escreva("REPROVADO ❌")
        }
    }
}
⚠️ As 3 Armadilhas Mortais das Condicionais:
  1. Encadeamento Matemático Inválido:
    ❌ se (idade >= 18 e <= 65) (O computador não entende "e <= 65" sozinho).
    ✅ se (idade >= 18 e idade <= 65) (Repita a variável!).
  2. Ponto e vírgula fantasma:
    ❌ se (nota >= 10); { escreva("Aprovado") } (O `;` encerra o `se` imediatamente, tornando o bloco `{}` sempre executado).
  3. Confundir Atribuição com Comparação:
    ❌ se (idade = 18) (Isso atribui 18 à idade e quase sempre dá erro de tipo).
    ✅ se (idade == 18) (Isso compara).

📌 Estrutura ESCOLHA / CASO

Ideal para comparar uma mesma variável com múltiplos valores fixos e exatos (como menus, dias da semana, opções de cor).

escolha (opcao) {
    caso 1:
        escreva("Domingo 🌞")
        pare  // Interrompe a execução do 'escolha'
    caso 2:
        escreva("Segunda-feira 🌙")
        pare
    caso contrario:
        escreva("Opção inválida ❌")
}
💡 Limitação Importante no Portugol: A estrutura escolha só funciona de forma confiável com variáveis do tipo inteiro, caractere ou cadeia. Não use com variáveis real (devido a problemas de precisão decimal) nem para verificar intervalos (ex: caso 10..20 não é padrão no Portugol Studio, use se/senao se para isso).

🔄 Estruturas de Repetição (Laços)

🎯 Aula: Laços de repetição: para, enquanto e faca-enquanto para automatizar tarefas repetitivas.

Imagine ter de escrever escreva("Olá") 1000 vezes. Seria absurdo! As estruturas de repetição (ou loops) permitem que o computador execute um bloco de código múltiplas vezes, de forma rápida e automática, até que uma condição de parada seja atingida.

⚖️ Comparação e Analogias do Mundo Real

EstruturaCaracterística PrincipalAnalogia do Mundo RealQuando usar
PARA 🔢 Número definido de repetições (usa contador). "Dar 10 voltas na pista de corrida." (Você sabe exatamente quantas). Tabuadas, percorrer vetores, contagens fixas.
ENQUANTO 🔁 Testa a condição ANTES de executar. Pode não executar nenhuma vez. "Enquanto o balde não encher, continue a deitar água." (Testa antes de deitar). Validações de dados, ler dados até encontrar um valor específico (sentinela).
FAÇA-ENQUANTO 🔂 Executa PELO MENOS 1 VEZ, testa a condição DEPOIS. "Prove a sopa. Enquanto não estiver boa, adicione sal e prove de novo." (Prova pelo menos uma vez). Menus de opções que precisam aparecer ao menos uma vez para o usuário escolher.

📝 Sintaxe e Exemplos Práticos

1. Estrutura PARA 🔢

Requer 3 elementos na declaração: inicialização, condição e incremento.

    escreva(i, " ")
    }
    // Resultado: 1 2 3 4 5

2. Estrutura ENQUANTO 🔁

A variável de controle deve ser declarada e inicializada antes do loop, e atualizada dentro dele.

    enquanto (i <= 5) {    // 2. Condição
    escreva(i, " ")
    i++                // 3. Incremento (⚠️ Obrigatório!)
    }

3. Estrutura FAÇA-ENQUANTO 🔂

inteiro opcao
    faca {
    escreva("Menu: 1-Jogar 0-Sair\n")
    leia(opcao)
    } enquanto (opcao != 0) // Ponto e vírgula no final é obrigatório aqui!
⚠️ As 3 Armadilhas Mortais dos Loops:
  1. O Loop Infinito: Esquecer de atualizar a variável de controle (ex: esquecer o i++). O programa nunca para. Solução no Portugol Studio: Clique no botão vermelho "Parar".
  2. Erro "Off-by-one" (Fora por um): Usar < em vez de <=. Se quiser contar até 5, i < 5 para no 4. Use i <= 5.
  3. Variável não inicializada: No enquanto, se você não der um valor inicial a i antes do loop, o computador não sabe com o que comparar e dá erro.

📚 Vetores e Matrizes

🎯 Aula: Estruturas de dados homogêneas para armazenar e processar múltiplos valores de forma organizada.

Até agora, cada variável guardava um único valor. Mas e se precisarmos guardar as notas de 30 alunos? Criar 30 variáveis (`nota1`, `nota2`...) seria um pesadelo. É aqui que entram os Vetores.

Vetor (Array): É uma única variável que armazena múltiplos valores do mesmo tipo, acessados individualmente por um índice (posição). 🏢 Analogia: Um edifício com apartamentos numerados. O nome do edifício é o nome do vetor, e o número do apartamento é o índice.

⚠️ Regra de Ouro (Base Zero): Em Portugol (e na maioria das linguagens como Python, Java, C), a contagem dos índices começa em 0! Ou seja, um vetor de tamanho 5 tem posições válidas de 0 a 4.

📝 Declaração e Inicialização

Existem duas formas principais de trabalhar com vetores:

// FORMA 1: Declarar vazio e preencher depois (usando loop)
inteiro notas[5]
para (inteiro i = 0; i < 5; i++) {
    escreva("Digite a nota: ")
    leia(notas[i])  // O 'i' muda de 0 a 4, acessando cada posição
}

// FORMA 2: Declarar e inicializar diretamente (para dados fixos)
cadeia dias[7] = {"Dom", "Seg", "Ter", "Qua", "Qui", "Sex", "Sab"}

🏆 Algoritmo Clássico: Encontrar Maior e Menor

Uma das tarefas mais comuns é varrer um vetor para encontrar extremos. O truque é assumir que o primeiro elemento é o maior (e o menor) inicialmente, e depois comparar com o resto.

inteiro vet[5] = {3, 7, 1, 9, 4}
inteiro maior = vet[0]  // Começa assumindo que a posição 0 é a maior
inteiro menor = vet[0]

// Começamos o loop do 1, pois o 0 já foi usado como referência
para (inteiro i = 1; i < 5; i++) {
    se (vet[i] > maior) { 
        maior = vet[i] 
    }
    se (vet[i] < menor) { 
        menor = vet[i] 
    }
}
escreval("Maior: ", maior, " | Menor: ", menor)
💀 A Armadilha Mortal: "Index Out of Bounds"
Se você declarar inteiro x[5] e tentar acessar x[5] ou x[-1], o programa dará erro de execução e fechará. Os únicos índices válidos são 0, 1, 2, 3 e 4. Sempre use i < tamanho no loop, nunca i <= tamanho.

🧮 Matrizes (Vetores Multidimensionais)

Uma matriz é um "vetor de vetores", organizada em linhas e colunas, como uma planilha do Excel ou um tabuleiro de xadrez. 📊

Para percorrer uma matriz, precisamos de dois loops aninhados (um dentro do outro): um para as linhas e outro para as colunas.

inteiro tabela[3][3]  // 3 linhas e 3 colunas

// Preenchendo a matriz com a tabuada do número da linha
para (inteiro linha = 0; linha < 3; linha++) {
    para (inteiro col = 0; col < 3; col++) {
        tabela[linha][col] = (linha + 1) * (col + 1)
    }
}

🧩 Funções e Procedimentos

🎯 Aula: Modularização, passagem de parâmetros (valor vs referência), retorno de valores e reutilização de código.

A medida que o teu programa cresce, ele começa a ficar confuso e difícil de manter. As funções resolvem isso através da modularização: dividir um problema grande em pequenos problemas (blocos de código) que podem ser reutilizados. 🏗️ Analogia: em vez de construir um carro inteiro de uma vez, constróis o motor, as rodas e o chassis separadamente e depois juntas tudo.

📊 Função vs Procedimento

Em Portugol, a palavra-chave é sempre funcao, mas o comportamento muda consoante ela retorna um valor ou não:

TipoRetorna valor?Palavra-chaveExemplo de uso
Função 🧮✅ Sim (gera um resultado)retorneCálculos, validações, conversões
Procedimento 🖨️❌ Não (apenas executa)NenhumaExibir menus, limpar tela, desenhar na tela

📝 Sintaxe no Portugol

// FUNÇÃO: Recebe dados, faz um cálculo e DEVOLVE o resultado
funcao somar(inteiro a, inteiro b): inteiro {
    inteiro resultado = a + b
    retorne resultado   // A palavra 'retorne' é obrigatória
}

// PROCEDIMENTO: Apenas executa uma ação (imprimir, por ex.)
funcao saudacao(cadeia nome) {
    escreva("Olá, ", nome, "! 👋")
    // Não tem 'retorne' nem ': tipo' no cabeçalho
}

💡 Exemplo de Uso no Programa Principal

programa {
    funcao inicio() {
        inteiro x = 5, y = 3, total
        
        // 1. Chamando a FUNÇÃO (o resultado é GUARDADO numa variável)
        total = somar(x, y)
        escreval("Soma: ", total)  // Saída: 8
        
        // 2. Chamando o PROCEDIMENTO (apenas executa e imprime)
        saudacao("Maria")  // Saída: Olá, Maria! 👋
    }
}
💀 A Armadilha Mortal Nº 1: Imprimir vs Retornar
Muitos alunos escrevem escreva(resultado) dentro da função quando deveriam usar retorne resultado.
  • escreva(): Mostra algo na tela. O computador não pode usar esse valor depois.
  • retorne: Entrega o valor nas mãos do programa principal. Ele pode guardá-lo numa variável e fazer mais cálculos com ele!

Regra de ouro: Se precisas usar o resultado do cálculo noutro lugar, use retorne.

TipoOnde é declaradaOnde pode ser usada
🏠 LocalDentro de uma funçãoApenas dentro daquela função. "Morre" quando a função termina.
🌍 GlobalFora de todas as funções (logo após programa {)Em todo o programa. (Evite usar em excesso — polui o código!).

🔗 Passagem de Parâmetros: Por Valor vs Por Referência

Quando passamos dados para uma função, podemos fazê-lo de duas formas:

1️⃣ Passagem por Valor (Padrão)

A função recebe uma cópia do valor. Se a função modificar o parâmetro, a variável original NÃO é alterada.

funcao tentar_mudar(inteiro num) {
    num = 100  // Muda apenas a cópia local
}
// A variável original continua com o valor dela.
2️⃣ Passagem por Referência

A função recebe o endereço de memória da variável. Se a função modificar o parâmetro, a variável original SIM é alterada. Em Portugol, usamos & antes do tipo.

funcao dobrar(inteiro &num) {
    num = num * 2  // Altera a variável original!
}
inteiro x = 5
dobrar(x)
escreva(x)  // Agora x vale 10!

💻 Exemplo Completo: Verificador de Primo Modular

Um programa bem estruturado usa funções para organizar a lógica:

programa {
    // FUNÇÃO: Recebe um número e retorna se é primo (logico)
    funcao eh_primo(inteiro n): logico {
        se (n <= 1) retorne falso
        
        para (inteiro i = 2; i < n; i++) {
            se (n % i == 0) retorne falso
        }
        retorne verdadeiro
    }
    
    // PROCEDIMENTO: Apenas exibe o resultado formatado
    funcao mostrar_resultado(inteiro num, logico primo) {
        se (primo) {
            escreva(num, " é PRIMO! ✅")
        } senao {
            escreva(num, " NÃO é primo. ❌")
        }
    }
    
    funcao inicio() {
        inteiro numero
        logico resultado
        
        escreva("Digite um número: ")
        leia(numero)
        
        resultado = eh_primo(numero)  // Chama e guarda o resultado
        mostrar_resultado(numero, resultado)  // Chama para exibir
    }
}

  • Após cada rodada, mostre o novo saldo e pergunte se deseja jogar novamente (use a técnica de caixa_baixa para validar a resposta "sim").
💡 Dica de Implementação da Lógica de Vitória

Para verificar se há 2 ou 3 números iguais sem complicar, você pode usar uma estrutura escolha ou múltiplos se:
se (n1 == n2 e n2 == n3) { premio = 50 }
senao se (n1 == n2 ou n1 == n3 ou n2 == n3) { premio = 10 }
senao { premio = 0 }

📊 Fluxogramas

🎯 Aula: Representação gráfica de algoritmos com símbolos padronizados (ISO 5807) e tradução para código.

Antes de escrever uma única linha de código, um bom programador planeja. O fluxograma é a planta baixa do seu programa. Ele permite visualizar a lógica, encontrar falhas e explicar o funcionamento para outras pessoas sem que elas precisem saber programar.

🔣 Símbolos Padrão (ISO 5807) e sua Tradução

Cada forma geométrica tem um significado específico e corresponde diretamente a um comando no Portugol:

SímboloNomeFunção no AlgoritmoEquivalente em Portugol
⬭ Oval Terminal 🚀/🏁 Indica o ponto de partida ou de chegada do fluxo. programa { e }
▱ Paralelogramo Entrada/Saída 📥📤 Recebe dados do exterior ou exibe resultados. leia() ou escreva()
▭ Retângulo Processo ⚙️ Cálculos, atribuições ou manipulação de dados. media = (n1 + n2) / 2
◇ Losango Decisão ❓ Testa uma condição. O fluxo se divide em caminhos. se (condicao) { ... } senao { ... }
◯ Círculo Conector 🔗 Une partes do fluxograma que estão em páginas ou áreas diferentes (evita linhas cruzadas). (Continuação lógica do código)
→ Seta Linha de Fluxo ➡️ Indica a direção e a ordem de execução das operações. A ordem sequencial das linhas de código.

🌉 A Ponte: Do Fluxograma para o Código

Veja como o fluxograma acima se traduz diretamente em Portugol. Note a correspondência exata entre as formas e os comandos:

programa {                           // ⬭ Terminal: INÍCIO
    funcao inicio() {
        inteiro num
        
        leia(num)                    // ▱ Entrada: Leia número
        
        se (num > 0) {               // ◇ Decisão: num > 0 ?
            escreva("Positivo ✅")    // ▱ Saída (Caminho Sim)
        } senao {
            escreva("Não positivo ❌")// ▱ Saída (Caminho Não)
        }
    }                                // ⬭ Terminal: FIM
}
💀 As 3 Armadilhas Mortais ao Desenhar Fluxogramas:
  1. O Losango de Três Saídas: Em programação básica, uma condição é sempre binária (Verdadeiro ou Falso). Nunca desenhe um losango com 3 setas saindo (ex: "Maior", "Menor", "Igual"). Divida em dois losangos encadeados (se / senao se).
  2. O Loop Infinito no Papel: Ao desenhar uma repetição, a seta que volta para cima deve passar por um losango de condição. Se não houver uma saída possível (ex: "Fim"), o fluxograma está errado.
  3. Símbolos Trocados: Usar um retângulo para leia ou um paralelogramo para um cálculo x = x + 1. Lembre-se: Retângulo = processamento interno; Paralelogramo = comunicação com o mundo exterior.
🎨 Dicas de Ouro para um Fluxograma Profissional:
  • 📏 Sempre comece com INÍCIO e termine com FIM (nunca deixe um caminho "pendurado").
  • ⬇️ O fluxo geral deve ser de cima para baixo ou da esquerda para a direita.
  • 📝 O texto dentro dos símbolos deve ser curto e direto (ex: "Leia idade", não "Pergunte ao usuário qual é a idade dele").
  • 🚫 Evite cruzar linhas. Se ficar confuso, use o símbolo de Conector (círculo com uma letra dentro, como "A").

🚀 Desafio Principal: O Caixa Eletrônico 🏧

Este é o "chefão" dos fluxogramas. Desenhe o fluxograma completo de um sistema bancário simples com as seguintes regras:

  • Saldo inicial de R$ 1000,00.
  • Exibir um menu com 4 opções: 1) Consultar Saldo, 2) Sacar, 3) Depositar, 4) Sair.
  • O sistema deve usar um loop para voltar ao menu após cada operação, até que o usuário escolha "4) Sair".
  • Regra de Negócio Crítica: Na opção "Sacar", o sistema deve verificar se o valor do saque é maior que o saldo atual. Se for, exibir "Saldo insuficiente" e não realizar o saque, voltando ao menu.
💡 Dica de Arquitetura do Fluxo

1. Comece com um losango principal para o loop do menu (ex: opcao != 4).
2. Dentro dele, coloque um losango grande de escolha/caso (ou vários se/senao se encadeados) para direcionar para as ações 1, 2, 3 ou 4.
3. No ramo do "Saque", insira um losango de validação: valor_saque <= saldo. O caminho "Sim" vai para o retângulo de saldo = saldo - valor_saque. O caminho "Não" vai para um paralelogramo de erro.
4. Todos os caminhos de ação devem ter uma seta que retorna à condição do loop principal, exceto a opção "Sair", que vai direto para o Terminal FIM.

💀 As 3 Armadilhas ao sair do Portugol:
  1. Case Sensitive (Sensível a maiúsculas): Ao contrário do Portugol, em Python e JS, Media, media e MEDIA são três variáveis diferentes. Escreve sempre em minúsculas (ou segue o padrão camelCase).
  2. A Tirania da Indentação (Python): Em Python, os espaços no início da linha definem os blocos de código (o que está dentro do if ou do for). Se a indentação estiver errada, o programa dá erro.
  3. Ponto e Vírgula e Chavetas (JS/C/C++): Esquecer o ; no final da linha ou as chavetas { } que agrupam blocos é o erro de sintaxe mais comum em JavaScript.
